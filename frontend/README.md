# CivicPulse Nexus Frontend

React + TypeScript + Vite executive governance interface.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Set `VITE_API_URL` in `.env.local` when the backend is not running on the default local URL.

The UI includes the six implementation phases: dashboard, analytics, reporting, audit/compliance, backend-connected data views and responsive executive UX.
